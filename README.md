## Before publishing
1. Verify the supplied phone number: `91994949494` appears to have 9 digits after +91. Replace it everywhere if one digit is missing.
2. Replace `YOUR-USERNAME` in `index.html`, `robots.txt`, and `sitemap.xml`.
3. When a custom domain is purchased, update canonical, Open Graph URL, JSON-LD URL, robots.txt and sitemap.xml to the final domain.
4. Add genuine business/FSSAI details, address/contact information, privacy policy and terms as applicable before commercial launch.
5. Add the real business UPI ID only after it is confirmed. Do not guess a UPI ID.

## GitHub Pages
Upload all files/folders to a GitHub repository. In Settings → Pages, choose the branch/folder containing `index.html`.

For a custom domain later, add it under GitHub Pages and configure the required DNS records at the domain provider.
